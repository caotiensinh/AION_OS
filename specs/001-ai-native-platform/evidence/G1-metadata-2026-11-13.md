## Root causes corrected

1. Ubuntu 24.04 hosted runner's AppArmor policy prevented BitBake user namespaces. **Fix:** use supported Ubuntu 22.04, no kernel security setting changed.
2. The `aion-health` recipe used forbidden `S = "${WORKDIR}"`. **Fix:** use `S = "${UNPACKDIR}"` and install files from `"${S}/..."`. A host regression check was added.
